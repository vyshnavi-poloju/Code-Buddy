# Student Performance Prediction using Machine Learning

## 📌 Project Overview

This project predicts a student's final score based on:
- Study Hours
- Attendance Percentage
- Previous Score

A Linear Regression machine learning model is used for prediction.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

## 🤖 Machine Learning Model

**Algorithm:** Linear Regression

The model is trained using student academic data and predicts the expected final score for a new student.

## 📊 Example Prediction

Input:
- Study Hours: 7
- Attendance: 80%
- Previous Score: 75

Predicted Final Score: **72.06**

## 📈 Model Evaluation

- Mean Absolute Error (MAE): **0.7**
- R² Score: **1.0**

> Note: This project uses a small sample dataset for learning and demonstration purposes. The evaluation results should not be considered real-world model accuracy.
